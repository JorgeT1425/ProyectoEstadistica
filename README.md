# EstadiApp · Analítica para Decidir

Aplicación web desarrollada en **Python + Streamlit** para el análisis estadístico, validación de esquemas y soporte a la toma de decisiones gerenciales, basada en los casos de negocio **MotoExpres S.A.S.** y **NovaApp**.

Proyecto desarrollado para la materia **Estadística y Probabilidad para Inteligencia de Negocios** de la Facultad de Inteligencia Artificial e Ingenierías de la Universidad de Caldas[cite: 5, 6].
